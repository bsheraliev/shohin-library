# Библиотека Shohin Airlines — публичная выгрузка

Самодостаточный HTML-реестр эксплуатационной документации ООО «Авиакомпания «Шохин Эйрлайнз»
для отправки коллегам: вкладки **Готовность к сдаче АГА**, Документы, Записи, По подразделениям,
Нормативная база, контрольная карта **GM-OPS-17** и указатель **IOSA**. Все данные встроены
в `index.html` — сервер и интернет для просмотра не нужны, файл открывается двойным щелчком.

Публикуется на **GitHub Pages** как статическая страница (в отличие от ссылки claude.ai,
не зависит от доступности claude.ai и открывается откуда угодно).

## Адрес после публикации

`https://bsheraliev.github.io/shohin-library/`

## ⚠️ Доступ

GitHub Pages на личном аккаунте — **публичный**: страницу увидит любой, у кого есть адрес.
Стоит `<meta name="robots" content="noindex, nofollow">` — поисковики её не индексируют, но
это не пароль. Ссылки на файлы внутри ведут в Google Drive и открываются только после входа
в Google (сами документы не раскрываются — только их статусы и метаданные). Если нужен доступ
строго по паролю — это делает бэкенд портала (вход по коду), а не GitHub Pages.

## Как обновить

Источник данных — рабочие реестры проекта. Порядок:

```bash
python "..\portal\tools\export_portal_html.py"   # пересобрать выгрузку из данных
python "..\portal\tools\build_ghpages.py"         # обернуть в index.html этой папки
git add -A && git commit -m "обновление выгрузки" && git push
```

Через 1–2 минуты GitHub Pages подхватит новую версию по тому же адресу.

`index.html` руками не править — он пересобирается. `.nojekyll` нужен, чтобы GitHub Pages
отдавал файл как есть.
